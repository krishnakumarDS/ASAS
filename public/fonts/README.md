# Dubai font

Drop the licensed font files here with these exact names:

- Dubai-Light.woff2   (300)
- Dubai-Regular.woff2 (400)
- Dubai-Medium.woff2  (500)
- Dubai-Bold.woff2    (700)

Until they are present (or Dubai is installed on the machine) browsers fall back to
Segoe UI → Roboto → Helvetica Neue → Arial.
